# Manga PSD Studio

تطبيق ويب محلي مستقل لترجمة صفحات المانجا **الإنجليزية واليابانية إلى العربية**، ثم تصدير
ملف **PSD** يحتوي على:

- خلفية منظفة من النص الأصلي (Inpainting).
- طبقة نص عربية قابلة للتعديل لكل فقاعة.
- خط عربي محدد بالاسم داخل طبقة PSD.
- إضافة خطوط مخصصة من جهازك (TTF / OTF / WOFF / WOFF2) وحفظها محليًا في المتصفح.
- طبقة معاينة نقطية اختيارية تضمن ظهور العربية بدقة المتصفح حتى لو اختلف تشكيل
  النص داخل محرك PSD.

التطبيق يعمل بالكامل في المتصفح. الصفحات لا تُرفع إلى خادم خاص بهذا المشروع؛ تذهب فقط
إلى مزود الترجمة الذي تختاره (Gemini أو OpenAI-compatible)، أو تبقى محلية في الوضع اليدوي.

> هذا المشروع منفصل عن إضافة Libre Manga Translator، ويعيد استخدام وحدات AGPL منها.
> راجع [الترخيص](#الترخيص) و[إشعارات الطرف الثالث](THIRD_PARTY_NOTICES.md)
> و[NOTICE](NOTICE).

## البدء السريع

```bash
cd D:\B\777\manga-psd-studio
npm install
npm run dev
```

افتح `http://127.0.0.1:5173/` في Chrome أو Edge حديث.

1. أضف صفحة أو عدة صفحات (PNG / JPG / WebP).
2. اختر لغة المصدر ومحرك الترجمة من لوحة الإعدادات.
3. اختر خط النص من الإعدادات، أو أضف خطًا مخصصًا من قسم **خطوط مخصصة**.
4. اضغط **تحليل الكل** أو **تحليل** على الصفحة.
5. راجع النص الأصلي والترجمة في الجدول وعدّل ما تريد.
6. اضغط **تركيب وتحديث PSD**، ثم **تنزيل PSD** أو **تنزيل كل PSD** (ZIP).

أول تحليل قد يستغرق وقتًا لأن المتصفح ينزّل موديل كشف النص. أول تركيب بجودة LaMa
ينزّل موديل التنظيف أيضًا. بعد ذلك تُستخدم النسخ المخزنة في `CacheStorage`.

## المتطلبات

- Node.js 20.19 أو أحدث (يُنصح بـ 22 LTS؛ تم الاختبار مع Node 26).
- npm.
- متصفح Chromium حديث (Chrome / Edge / Brave). Firefox قد يعمل لكن لم يُختبر.
- اتصال بالإنترنت في أول تشغيل لتنزيل الموديلات، إلا إذا كانت مخزنة مسبقًا.
- مساحة تخزين للموديلات: Comic Text Detector ~95 MB، LaMa ~207 MB، RT-DETR ~11 MB.
- ذاكرة كافية: الصفحات الكبيرة + LaMa تحتاج عدة مئات من الميغابايت من RAM.

التطبيق يستخدم ONNX Runtime Web على WASM بخيط واحد افتراضيًا. هذا أبطأ من GPU لكنه
أكثر ثباتًا عبر المتصفحات والاستضافات، وهو مناسب لأولوية الجودة على السرعة.

## إعداد الترجمة

### 1) Gemini Vision (موصى به للجودة)

1. احصل على مفتاح من Google AI Studio.
2. في الإعدادات: **محرك الترجمة = Gemini Vision**.
3. الصق المفتاح واختر الموديل:
   - `gemini-2.5-flash` — توازن جيد بين السرعة والجودة.
   - `gemini-2.5-pro` — جودة أعلى وتكلفة/زمن أكبر.
4. اختر لغة المصدر: اليابانية أو الإنجليزية أو كشف تلقائي.

المفتاح يُحفظ في `localStorage` داخل هذا المتصفح فقط. لا ترفع نسخة عامة من التطبيق
ومفاتيحك بداخلها.

### 2) OpenAI-compatible Vision (محلي أو سحابي)

يدعم أي خادم يقبل صيغة OpenAI Chat Completions مع `image_url`، مثل:

- **Ollama** محليًا:
  ```bash
  ollama pull qwen2.5vl:7b
  ```
  ثم:
  - Base URL: `http://127.0.0.1:11434/v1`
  - Model: `qwen2.5vl:7b`
  - API key: اتركه فارغًا.
  - إذا منع Ollama طلبات المتصفح، شغّله مع:
    ```powershell
    $env:OLLAMA_ORIGINS="http://127.0.0.1:5173"
    ollama serve
    ```
- **LM Studio**: شغّل Local Server، ثم Base URL مثل `http://127.0.0.1:1234/v1`.
- **OpenAI**: `https://api.openai.com/v1` + مفتاح + موديل vision.

يجب أن يدعم الموديل الصور فعلًا. الموديلات النصية فقط ستعيد أخطاء أو ترجمة بلا قراءة
للصفحة.

### 3) الوضع اليدوي

يُستخدم للكشف فقط دون أي API. بعد التحليل اكتب الترجمة العربية في الجدول، ثم اضغط
**تركيب وتحديث PSD**. مناسب إذا كنت تريد ترجمة بنفسك أو اختبار الكشف والتنظيف.

## طريقة العمل

```text
صورة الصفحة
   ↓
كشف مناطق النص (Comic Text Detector أو RT-DETR)
   ↓
ترجمة رؤيوية (Gemini / OpenAI-compatible) أو إدخال يدوي
   ↓
تنظيف النص الأصلي (LaMa أو المسار السريع)
   ↓
رسم الترجمة العربية على الصفحة + إنشاء طبقة نص شفافة
   ↓
توليد PSD عبر ag-psd
```

- الكشف الافتراضي: **Comic Text Detector** (أدق في النص الياباني والفقاعات).
- بديل أخف: **RT-DETR** (~11 MB).
- التنظيف الافتراضي: **LaMa** (جودة أعلى)، مع مسار سريع بدون موديل إضافي.
  المسار السريع مناسب للمعاينة فقط؛ قد يترك آثارًا فاتحة داخل الفقاعات الداكنة.
  استخدم **LaMa** للصفحات النهائية.
- الترجمة تعتمد على رؤية الصفحة كاملة مع صناديق مرقمة، وليس OCR محليًا. هذا يساعد
  في قراءة النص العمودي الياباني وفهم سياق المشهد.

## ملاحظات PSD المهمة

- كل فقاعة مترجمة تصبح **طبقة نص قابلة للتعديل** باسم `Bubble 001 — editable`.
- الخلفية المنظفة طبقة منفصلة باسم `Background — cleaned page`.
- عند تفعيل **طبقة المعاينة النقطية للعربية** (الافتراضي):
  - تظهر طبقة `Preview — raster Arabic text` بالعربية المشكَّلة كما رسمها المتصفح.
  - تظل طبقات النص القابلة للتعديل **ظاهرة** أسفلها، ومزوّدة بصورة نقطية للطبقة
    حتى لا تظهر فارغة قبل تحديث Photoshop.
  - أخفِ طبقة المعاينة (`Preview`) من لوحة الطبقات عندما تريد رؤية النص الحي وتعديله.
- ملف PSD يخزّن **اسم الخط** فقط، ولا يضمّن ملف الخط. ثبّت الخط المختار على الجهاز
  الذي سيفتح الملف، وإلا سيستبدله Photoshop.
- PSD بدقة 72 PPI، بحيث تساوي البكسل نقطة تقريبًا.
- عند فتح الملف قد يعرض Photoshop تنبيه تحديث طبقات النص. هذا متوقع لأن `ag-psd`
  يكتب بيانات النص لكنه لا يعيد رسم الصورة النقطية للطبقة. اختر تحديث/Update.
  الصورة النقطية المضمّنة في الطبقة تجعل النص ظاهرًا حتى قبل الضغط على Update.
- للعربية داخل Photoshop:
  - فعّل محرك النص الشرقي/World-Ready إن لم يكن مفعّلًا.
  - إذا ظهر النص معكوسًا أو غير متصل، جرّب تعطيل **RTL** في الإعدادات وإعادة التركيب.
  - إذا فشل تشكيل العربية في طبقة النص، استخدم طبقة المعاينة النقطية كنسخة بصرية
    مضمونة، وعدّل النص في طبقة `editable` عند الحاجة.
- موضع النص داخل PSD محسوب ليطابق المعاينة، لكنه قد يحتاج تعديلًا بسيطًا بعد تركيب
  الخط الفعلي. راجع أول صفحة دائمًا قبل تصدير دفعة كاملة.

## الخطوط

الخطوط المضمّنة في `public/fonts`:

| الخط | ملف | ترخيص |
|---|---|---|
| Noto Naskh Arabic | `NotoNaskhArabic-Regular.ttf` | OFL-1.1 |
| Noto Sans Arabic | `NotoSansArabic-Regular.ttf` | OFL-1.1 |
| Amiri | `Amiri-Regular.ttf` | OFL-1.1 |

- يمكن تنزيل الخط من داخل لوحة الإعدادات، ثم تثبيته على Windows:
  انقر بزر الفأرة الأيمن على الملف → **Install** (أو Install for all users).
- أعد تشغيل Photoshop بعد تثبيت الخط.
- نسخ تراخيص OFL موجودة في `licenses/fonts/`.
- إذا اخترت **خط النظام العربي**، فسيعتمد PSD على `SegoeUI` أو الخط المتاح؛ النتيجة
  تختلف بين الأجهزة.

### خطوط مخصصة

- من الإعدادات → **خطوط مخصصة** اضغط **إضافة خط** واختر ملف
  `TTF` أو `OTF` أو `WOFF` أو `WOFF2`.
- يقرأ التطبيق اسم PostScript تلقائيًا، ويضيف الخط إلى قائمة الخطوط ويختاره مباشرة.
- يُحفظ ملف الخط في **IndexedDB داخل هذا المتصفح فقط**، ولا يُرفع إلى أي خادم.
- يمكنك تنزيل ملف الخط من بطاقة الخط المخصص لتثبيته على جهازك.
- ملف PSD يخزّن **اسم PostScript فقط**؛ يجب تثبيت الخط على الجهاز الذي سيفتح PSD
  حتى يظهر النص بنفس الشكل. إذا لم يكن الخط مثبتًا، قد يستبدله Photoshop بخط آخر.
- حذف الخط من قائمة الخطوط المخصصة يحذفه من تخزين المتصفح، لكنه لا يحذف نسخة
  PSD أو نسخة الخط المثبتة على نظامك.
- الخطوط المخصصة مسؤولية المستخدم من حيث الترخيص؛ لا ترفع خطًا تجاريًا لا تملك
  حق استخدامه أو إعادة توزيعه.

## البناء والنشر

```bash
npm run check     # TypeScript
npm run build     # إخراج الإنتاج في dist/
npm run preview   # معاينة dist محليًا
```

بعد البناء ينسخ `postbuild` ملفات `LICENSE` و`NOTICE` و`THIRD_PARTY_NOTICES.md`
و`licenses/` إلى `dist/legal/`، ويجمع تراخيص حزم npm وقت التشغيل في
`dist/legal/npm/` تلقائيًا.

### استضافة الإنتاج

انشر محتويات `dist/` على أي استضافة ثابتة. يفضّل إضافة الترويسات:

```http
Cross-Origin-Opener-Policy: same-origin
Cross-Origin-Embedder-Policy: require-corp
```

التطبيق مضبوط على خيط WASM واحد، لذلك قد يعمل حتى لو لم تدعم الاستضافة هذين
الترويسات، لكن الترويسات تزيد التوافق مع ONNX Runtime وتسمح بميزات SharedArrayBuffer
إن غيّرت عدد الخيوط لاحقًا.

في وضع التطوير، يمرر Vite تنزيلات الموديلات عبر `/hf` و`/gh` لتجنب قيود CORS في
المتصفح. في بناء الإنتاج، تُستخدم روابط Hugging Face وGitHub الأصلية مباشرة. إذا كنت
تستضيف الموديلات بنفسك، عدّل عناوين الموديلات في `src/lib/configs.ts` أو أضف وكيلًا
على نفس النطاق.

## النشر على GitHub

المشروع مهيأ للنشر كمستودع مصدر مفتوح. الملفات القانونية المطلوبة موجودة:
`LICENSE`، `NOTICE`، `THIRD_PARTY_NOTICES.md`، و`licenses/`، مع نص AGPL كامل.

المستودع المنشور: <https://github.com/lifemoon2456/psdTRManga->

### ربط المستودع ودفعه

تمت تهيئة مستودع Git محليًا على فرع `main` مع commit أول، وربطه بالمستودع
`origin`. لأي نسخة جديدة:

```bash
git remote add origin https://github.com/lifemoon2456/psdTRManga-.git   # إن لم يكن مضافًا
git push -u origin main
```

- التزام Git الأول يستخدم هوية Git المحلية. إذا كنت لا تريد ظهور بريدك في
  تاريخ المستودع، عيّن بريد GitHub الخاص قبل الدفع:
  `git config user.email "USER@users.noreply.github.com"` ثم
  `git commit --amend --reset-author --no-edit`.
- `dist/` و`node_modules/` مستبعدان عبر `.gitignore`؛ لا ترفعهما.
- ملفات الموديلات (`.onnx`) مستبعدة أيضًا؛ تُنزّل وقت التشغيل.
- لا ترفع `.env` أو مفاتيح API. المفاتيح تُدخل في الواجهة وتُحفظ محليًا فقط.
- لا ترفع صفحات مانجا محمية بحقوق النشر إلى المستودع أو إلى قضايا GitHub.

### قبل أول نشر

- شغّل `npm ci` ثم `npm run check` ثم `npm run build`.
- تحقق من عدم وجود أسرار: `git status` و`git diff --cached`.
- أضف وصفًا للمستودع ووسومًا مثل `manga`, `arabic`, `psd`, `translation`.
- إذا استضفت نسخة معدلة كخدمة شبكة، وفّر الكود المصدري للمستخدمين وفق AGPL §13.
- ملفات الترخيص تُنسخ تلقائيًا إلى `dist/legal/` عند البناء، لذا أرفقها مع أي إصدار.

المستودع يحتوي أيضًا على `CONTRIBUTING.md` و`SECURITY.md` وسير عمل CI في
`.github/workflows/ci.yml` لتشغيل الفحص والبناء عند كل دفع.

## الأمان والخصوصية

- لا يوجد خادم خلفي لهذا التطبيق ولا تتبع ولا تحليلات.
- الصور تبقى في الذاكرة المحلية (Blob URLs) ولا تُرسل إلا إلى مزود الترجمة المختار.
- في الوضع اليدوي لا تُرسل الصور إلى أي خدمة.
- مفاتيح API تُحفظ في `localStorage`. هذا مناسب لجهاز شخصي، وليس لاستضافة عامة.
- لا تضع مفاتيح حقيقية في مستودع Git أو في نسخة منشورة للعامة.
- استخدم مفتاحًا بصلاحيات محدودة، وراقب الاستخدام من لوحة المزود.

## الاختبار والتطوير

تم اختبار المسار التالي بنجاح أثناء التطوير:

- RT-DETR على صفحة تجريبية → كشف 3 مناطق.
- Comic Text Detector على صفحة تجريبية → كشف منطقة نص.
- وضع يدوي + LaMa → خلفية منظفة + PSD بطبقات نص.
- OpenAI-compatible mock → 3 ترجمات + PSD.
- قراءة PSD مرة أخرى باستخدام `ag-psd` للتأكد من وجود طبقات النص والخط والاتجاه،
  وأنها مرئية وتحمل صورة نقطية للطبقة بدل أن تظهر فارغة.
- بناء الإنتاج (`npm run preview`) → كشف وتركيب PSD، وتنزيل ZIP بصفحة واحدة.

لتشغيل خادم OpenAI-compatible وهمي بدون مفتاح:

```bash
node scripts/mock-openai.mjs
```

ثم في الإعدادات:

- المحرك: OpenAI-compatible
- Base URL: `http://127.0.0.1:8787/v1`
- Model: `mock-vl`
- API key: فارغ

هذا الخادم للاختبار فقط ويعيد ترجمات ثابتة.

## القيود الحالية

- لا يوجد OCR محلي في هذه النسخة؛ الترجمة رؤيوية عبر API أو يدوية.
- لا يدعم PDF أو ملفات CBZ مباشرة؛ أضف صور الصفحات.
- لا يوجد تراجع/Undo شامل داخل الجدول.
- جودة الكشف تعتمد على وضوح الصفحة ونوع المانجا. راجع دائمًا الصفحات قبل التصدير.
- تشكيل العربية داخل PSD يعتمد على محرك النص في Photoshop/المحرر. طبقة المعاينة
  النقطية هي الضمان البصري، وطبقات النص هي نسخة التعديل.
- لم يتم التحقق من PSD داخل Photoshop أو Photopea في بيئة التطوير الحالية؛ تم التحقق
  من بنية الملف وطبقاته عبر `ag-psd`. اختبر أول ملف على جهازك قبل دفعة كبيرة.
- Gemini لم يُختبر بدون مفتاح API. مسار OpenAI-compatible تم اختباره بخادم وهمي.
